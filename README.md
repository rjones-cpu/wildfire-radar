# LodgeX Wildfire Radar (prototype)

Animated 150 km radar centered on a **placeholder** camp pin (default Cold Lake area). Fetches live active Alberta wildfires from the Government of Alberta ArcGIS FeatureServer.

- Live: open `index.html` (or the Pages URL)
- Test pings: add `?test=1` (sample data only)

Data source: [Active Alberta Wildfire Locations](https://geospatial.alberta.ca/mimas/rest/services/wildfire/alberta_fire_status_by_category_group/FeatureServer/0)

Not production LodgeX hosting.
